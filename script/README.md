## Running the scripts

These are unchanged copies of the original scripts. Some scripts contain absolute paths from the original analysis environment. Before running them, install the packages referenced in each script and adjust its input paths, output paths, and working directory to match your local data locations. Copying a script into this directory does not change its path settings.

The scripts have not been rerun as part of this directory reorganization.

## Maintaining the copies

Use the scripts in the figure-specific directories as the primary versions. If a script is updated, refresh its copy here to keep the two versions identical.
